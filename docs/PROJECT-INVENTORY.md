# EBASE 页面与功能清单

更新日期：2026-09-03
当前阶段：高保真前端与 ThinkPHP 8 API 渐进联调。

## 1. 当前实现状态

- 前端：Vue 3 + TypeScript + Vite + Vue Router。
- 图标：Lucide Vue Next。
- 数据：成员目录与订单管理已接入统一 API Client 和 ThinkPHP 8 API；其余部分页面仍使用内置模拟数据，部分 CRUD、流程表单、收藏和最近访问使用 `localStorage` 持久化。
- 认证：已有登录交互原型，但尚未接入 JWT、刷新令牌、验证码或后端会话。
- 后端：仓库已包含 ThinkPHP 8、MySQL Schema、JWT/Refresh Token、订单和成员等首批接口；Redis、队列、对象存储及外部支付/物流适配仍需按开发规范继续完成。

因此，“页面存在”不等于“生产业务能力已经完成”。接后端时不得保留 `localStorage` 作为真实业务数据源。

## 2. 全局框架

- 后台框架：固定侧栏、顶部工具栏、全局搜索、店铺切换、通知和个人头像。
- 响应式导航：移动端抽屉侧栏。
- 认证框架：登录/找回密码使用独立布局，不显示后台导航。
- 通用视觉：Noto Sans SC + Manrope、Lucide 图标、统一颜色/圆角/边框/表单字体。
- 通用反馈：全局成功、错误、警告、信息 Toast，支持自动关闭、手动关闭和无障碍播报。
- 通用上传：业务流程附件支持点击选择、拖拽、类型/大小校验、上传进度、完成状态与移除。
- 通用表格状态：统一加载、错误、空数据与筛选无结果布局，支持重试、清除筛选或创建首条记录等恢复动作。
- 通用日期范围：控制台与数据报表复用日期范围组件，支持近 3 日、近 7 日、近 30 日及自定义起止日期，自定义范围最长 180 天。
- 通用工具栏下拉：控制台和一级业务模块筛选复用整块可点击的下拉组件，使用中性焦点反馈、浮层选项、当前项高亮，并支持点击外部与 Esc 关闭。
- 顶部工具：全局搜索支持 `⌘/Ctrl + K`、键盘选择和路由跳转；帮助面板支持内容筛选、快捷键和管理员联系方式；通知中心支持未读状态、全部已读和业务跳转。

## 3. 已有页面

### 认证与成员

- `/login`：成员邮箱登录、密码显隐、保持登录、SSO 占位入口。
- `/forgot-password`：找回密码、发送成功状态。
- `/member/profile`：个人资料、头像上传/更换/移除、账号安全、登录设备、通知偏好、退出登录。
- `/settings/members`：成员指标、状态标签、搜索、筛选、目录表格和分页外观。
- `/settings/members/invite`：邀请成员、部门/角色/数据范围、安全策略。
- `/settings/members/:id`：成员资料编辑、权限设置、重置密码和停用账号入口。
- `/403`：无权限访问页，说明权限原因并提供返回与控制台恢复入口。
- `/500`：系统错误页，提供请求标识、返回与重新加载入口。
- 未知路由：统一进入 404 页面不存在状态，不再展示空白内容区。

### 控制台与一级模块

- `/`：运营控制台，含经营指标、销售趋势、履约状态、待办、库存预警和最新订单。
- `/orders`：订单管理，列表、关键词、状态、渠道、店铺、分页、状态数量、指标和右侧订单详情均由 `/api/v1/orders` 驱动。
- `/logistics`：物流履约。
- `/products`：产品管理，列表接入 `/api/v1/operations/products`，支持服务端分页、搜索、完整页码窗口及 URL 页码状态。
- `/inventory`：库存中心。
- `/users`：消费者/会员管理，注意不是内部成员。
- `/content`：内容中心。
- `/coupons`：优惠券管理。
- `/marketing`：营销活动。
- `/reports`：数据报表。
- `/storefront`：独立站控制中心，包含站点经营指标、健康度和商品、订单、会员、支付入口。

### 独立站管理

- `/storefront/sites`：站点列表与经营配置。
- `/storefront/sites/new`：创建独立站，配置语言、币种、时区、品牌、域名和默认 SEO。
- `/storefront/sites/:id`：站点设置与状态管理。
- `/storefront/theme`：首页区块、页头页脚和主题发布管理。
- `/storefront/navigation`：页头、页脚和移动端导航菜单管理。
- `/storefront/pages`：自定义页面、政策页面和活动专题管理。
- `/storefront/domains`：域名、DNS、HTTPS 和证书状态管理。
- `/storefront/seo`：标题模板、结构化数据、Sitemap 和重定向规则。

以上管理页均包含指标、搜索、列表、新增、编辑、删除和统一结果通知。当前数据为高保真原型数据。

上述九个一级模块复用 `ModuleView.vue`，具备指标、页签、搜索、筛选、勾选、批量操作、表格、分页和侧边洞察。已接入 operations API 的产品、库存、用户、物流、内容、优惠券和营销列表使用服务端分页；分页器支持上一页、下一页、首尾页、相邻页和省略号，并把当前页同步到 URL Query。一级模块的首个页签显示 API 返回的真实总数；右侧洞察项均提供点击反馈，不保留无响应箭头。

### 四步业务流程

- `/orders/:id`：订单概览、商品与支付、履约记录、售后与备注。
- `/logistics/:id`：异常概览、收件信息、物流轨迹、处理记录。
- `/products/new`：基础信息、默认商品描述、四张本地占位商品图、销售规格、媒体素材、国内平台发布和独立站发布。独立站发布包含站点、状态、标题、Slug、渠道价格、库存策略、SEO 和专属描述。
- `/inventory/restock`：补货清单、供应商、到货计划、审批记录。
- `/users/:id`：用户概览、消费行为、标签人群、触达记录。
- `/content/new`：内容编辑、关联商品、发布渠道、排期与审核。
- `/coupons/new`：基础规则、适用范围、领取限制、投放计划。
- `/marketing/new`：活动信息、优惠机制、渠道与人群、预算审批。
- `/reports/analysis`：核心趋势、渠道贡献、商品结构、用户结构。
- `/settings/roles/:id`：角色信息、功能权限、数据权限、成员与日志。

流程页包含步骤导航、编辑表单、摘要、时间线、附件入口和本地草稿保存。

### 功能地图与二级 CRUD

- `/features`：搜索、业务分组、收藏、最近访问和功能状态。
- `/features/refunds`：售后退款中心。
- `/features/warehouses`：仓库管理。
- `/features/categories`：类目与品牌。
- `/features/suppliers`：供应商管理。
- `/features/segments`：用户分群。
- `/features/assets`：素材库。
- `/features/coupon-delivery`：批量发券。
- `/features/approvals`：营销审批中心。
- `/features/report-builder`：自定义报表。
- `/features/audit-logs`：操作日志。

这些二级页复用 `SecondaryView.vue` 和 `secondaryConfigs.ts`，具备搜索、阶段卡片、查看、新增、编辑、删除确认、必填验证、状态选择和本地持久化。

### 系统设置

`/settings` 包含八组配置：企业信息、成员与角色、店铺与渠道、仓库配置、支付配置、消息通知、安全设置、操作日志。

## 4. 当前仅为原型的交互

以下能力只有 UI/本地行为，接后端时必须替换：

- 登录、退出、找回密码和 SSO。
- 所有列表查询、分页、筛选、批量操作和导出。
- 所有 CRUD、审批、保存草稿和附件上传。当前上传进度为原型模拟，正式接入时必须替换为对象存储上传状态。
- 成员邀请、权限变更、密码重置、双重验证和设备退出。
- 支付、物流轨迹、库存锁、订单状态、通知和操作日志。
- 图表、经营指标和预警数据。

## 5. 建议后续优先级

1. 建立 ThinkPHP 8 基础工程、统一响应/异常、JWT、权限中间件和 OpenAPI。
2. 接通成员登录、刷新令牌、个人会话、角色权限与操作日志。
3. 完成商品、SKU、库存、订单的核心数据模型与接口。
4. 建立 Redis 库存锁和队列，完成订单超时取消与库存回补。
5. 接入微信支付服务层和可靠回调流程。
6. 按业务节奏接入物流、优惠券、发票、对象存储与消息通知。
